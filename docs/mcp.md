# Стандарты 1С в ИИ-помощнике

Вы можете спросить у ИИ-помощника: «Почему в 1С не рекомендуют модальные окна?»
и попросить его найти ответ в стандартах v8std.ru со ссылкой на правило.
Для этого нужно один раз подключить к помощнику наш справочник.

## Что такое ИИ и MCP

ИИ-помощник — программа, с которой можно общаться обычным текстом.
Вы задаёте вопрос, она составляет ответ. Но помощник может ошибаться:
даже уверенное объяснение стоит сверять с источником.

MCP — способ подключать к ИИ-помощнику внешние источники и инструменты.
Через MCP v8std помощник может искать материалы этого сайта и читать найденные
стандарты. Вам достаточно задавать вопросы в привычном чате.

Например, вы просите объяснить предупреждение о модальном окне. Помощник
обращается к v8std, находит описание
<a class="diagnostic-chip" href="diagnostics/bslls/UsingModalWindows.md">bslls:UsingModalWindows</a>
и связанный стандарт, затем объясняет правило и даёт ссылку для проверки.

## Как подключить

Понадобится приложение с ИИ-помощником, которое поддерживает MCP.
В его настройках найдите раздел MCP или подключения внешних инструментов
и добавьте сервер:

- **Название:** `v8std`.
- **Адрес:** `https://ai.v8std.ru/mcp`.

Это адрес для настроек помощника: отдельного чата при открытии в браузере нет.
Способ добавления зависит от приложения; если оно просит конфигурационный файл
вместо адреса, воспользуйтесь его инструкцией по подключению MCP.

После подключения убедитесь, что `v8std` включён. Если приложение попросит
разрешение обратиться к нему, подтвердите запрос, чтобы помощник мог найти материал.

## Попробуйте первый вопрос

Скопируйте в чат:

> Найди через v8std стандарт о модальных окнах в 1С. Объясни простыми словами,
> в чём проблема, и дай ссылку на стандарт.

Так же можно попросить найти правило по его номеру или объяснить предупреждение
из проверки кода. Названия внутренних инструментов и специальные команды
для этого знать не нужно.

Откройте ссылку из ответа и проверьте, подходит ли правило к вашей задаче.
Если помощник отвечает без источника, попросите его обратиться к v8std
и привести найденный материал.

MCP v8std возвращает справочные материалы. Сам сервис не изменяет ваш проект
и не выполняет полную проверку кода. Он получает текст запросов, которые
отправляет помощник, поэтому не передавайте в публичный сервис закрытый код
и конфиденциальные данные.

## Как запустить на своём компьютере

Есть два варианта: запустить только MCP или сайт вместе с MCP.
В первом случае справочник скачивается с v8std.ru, а ссылки из ответов ведут
на публичный сайт. Во втором — MCP берёт справочник из локального сайта,
и материалы можно читать на своём компьютере.

Понадобится установленный и запущенный Docker с Docker Compose.
Команды ниже рассчитаны на терминал macOS, Linux или WSL в Windows.
Для скачивания образов нужен интернет; собирать проект из исходников не требуется.

### Только MCP

Создайте папку `v8std-mcp`, а в ней файл `compose.yaml`.
Скопируйте в файл весь текст:

```yaml
--8<-- "delivery/local/compose.mcp.yaml"
```

Откройте терминал в этой папке и запустите MCP:

```bash
docker compose up -d
docker compose ps
```

При первом запуске MCP скачает поисковый индекс — подготовленный справочник
для поиска по стандартам. Он сохранится в Docker-томе и будет использоваться
при следующих запусках. Для получения обновлений справочника нужен доступ
к v8std.ru и ai.v8std.ru.

Дождитесь состояния `healthy` у MCP. Если он не готов, посмотрите сообщения:
`docker compose logs mcp`.

В настройках ИИ-помощника укажите адрес `http://127.0.0.1:18766/mcp`
и способ подключения **Streamable HTTP**.

Чтобы остановить MCP, выполните в той же папке `docker compose down`.
Для повторного запуска — `docker compose up -d`. Скачанный индекс сохранится.

### Сайт и MCP

Docker Compose запускает оба контейнера и соединяет их между собой.
MCP получает индекс из контейнера сайта; обращаться за ним к публичному серверу
не нужно. После скачивания образов сайт и MCP могут работать без интернета.

Если вы уже запустили отдельный MCP, сначала выполните `docker compose down`
в его папке. Оба варианта используют один порт.

Создайте отдельную папку `v8std-local`, а в ней файл `compose.yaml`.
Скопируйте в файл весь текст:

```yaml
--8<-- "delivery/local/compose.yaml"
```

Рядом создайте файл `.env` со следующим содержимым.
Оба образа взяты из одного опубликованного выпуска:

```dotenv
V8STD_SITE_IMAGE=ghcr.io/zeegin/v8std-site:sha-58fff9f7cce57e98c884e01eded360236cfa47ee
V8STD_MCP_IMAGE=ghcr.io/zeegin/v8std-mcp:sha-58fff9f7cce57e98c884e01eded360236cfa47ee
```

Откройте терминал в папке `v8std-local` и запустите контейнеры:

```bash
docker compose --profile mcp up -d
docker compose --profile mcp ps
```

Дождитесь состояния `healthy` у MCP. Если он не готов, посмотрите сообщения:
`docker compose --profile mcp logs mcp`.

- **Сайт в браузере:** [http://v8std.localhost:18765/](http://v8std.localhost:18765/).
- **Адрес MCP для ИИ-помощника:** `http://127.0.0.1:18766/mcp`.
- **Способ подключения:** Streamable HTTP.

Чтобы остановить сайт и MCP, выполните в той же папке:

```bash
docker compose --profile mcp down
```

Скачанный индекс останется в Docker-томе. Для повторного запуска используйте
`docker compose --profile mcp up -d`. В этом варианте версия справочника
определяется выбранным образом сайта.

### Что подключается к локальному MCP

Адрес `127.0.0.1` доступен приложениям на вашем компьютере. Облачный помощник,
который подключается к MCP со своего сервера, не сможет использовать этот адрес.
Приведённые команды не открывают доступ к контейнерам из внешней сети.

Локальный MCP выполняет поиск на вашем компьютере, но сам ИИ-помощник
может отправлять переписку своему облачному провайдеру. Его подключение
и правила обработки данных настраиваются отдельно.
