# Внутренние проектные документы

Каталог `spec/` не входит в публикуемый сайт. Пользовательский корпус сайта
находится в `docs/`.

Документы разделяются по назначению:

- `spec/adr/` — короткие записи об одном архитектурном решении;
- `*-design.md` — изменяемые технические контракты и проект;
- `*-plan.md` — исполнимые планы реализации.

ADR отвечает на вопрос «почему выбрано это направление», но не фиксирует
детали реализации. Изменение URI, JSON schema, UI layout, metric labels, тестов
или порядка rollout обычно изменяет design или plan, а не отменяет ADR.

Новый ADR заменяет старый только тогда, когда меняется само решение. В нём
указывается ровно один заменённый ADR. Добавление независимого механизма
оформляется отдельным ADR и не отменяет связанные решения.
