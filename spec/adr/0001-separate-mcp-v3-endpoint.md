# ADR-0001: Отдельный endpoint для MCP v3

- Статус: принято
- Дата: 2026-08-14

## Контекст

MCP v2 опубликован на `/mcp`. Его контракт используют клиенты, которым нужны
существующие tools и агрегированные resources. Изменение этого контракта на
месте сломает совместимость и свяжет откат v3 с работающим v2.

## Решение

MCP v3 публикуется как независимый контракт на `/v3/mcp` и запускается в
отдельном процессе. `/mcp` продолжает обслуживать v2 без перенаправления и без
даты отключения.

Клиент выбирает версию URL подключения. Ошибка запуска, обновления или отката
v3 не должна останавливать v2.

## Отклонённые варианты

- заменить контракт `/mcp` на месте;
- согласовывать прикладную версию на одном MCP endpoint.

## Последствия

- v2 и v3 можно разворачивать и откатывать независимо;
- требуется поддерживать два runtime-процесса и два публичных маршрута;
- изменение внутреннего контракта v3 не требует пересмотра этого ADR;
- замена `/mcp` или объединение версий потребует нового ADR, заменяющего только
  ADR-0001.
