# ADR-0004: Чтение страниц MCP v3 через Resources

- Статус: принято
- Дата: 2026-08-14

## Контекст

В MCP v2 полный Markdown страницы читается инструментом `v8std_get_page`.
Протокол MCP предоставляет для документов отдельный примитив Resources. В v3
нужно выбрать один основной способ чтения, иначе tools и Resources будут
дублировать один контракт.

## Решение

В MCP v3 полный Markdown страницы читается через `resources/read`.
`v8std_get_page` в v3 отсутствует. Tools выполняют поиск и анализ и могут
возвращать ссылки на доступные resources, но не встраивают полное тело страницы.

Клиенты без поддержки Resources продолжают использовать MCP v2.

## Отклонённые варианты

- сохранить `v8std_get_page` как основной способ чтения v3;
- одновременно поддерживать в v3 два равноправных способа полного чтения;
- удалить `v8std_get_page` из v2.

## Последствия

- назначение tools и Resources не дублируется;
- tool-only клиентам для полного чтения нужен v2;
- URI, templates, pagination, snapshot и tool result schema определяются в
  design и могут изменяться без отмены ADR-0004;
- возврат полного чтения через tool в v3 потребует нового ADR, заменяющего только
  ADR-0004.
