# ADR-0002: Публичный агрегированный мониторинг MCP

- Статус: принято
- Дата: 2026-08-14

## Контекст

Текущий `/monitoring/` показывает статистику MCP, но ориентирован на v2 и
публикует последние поисковые запросы. После запуска v3 нужен единый обзор
агентов, используемой API-версии и MCP-операций. Пользовательский ввод и
эксплуатационные детали публиковать нельзя.

## Решение

Сохраняется один публичный статический dashboard для v2 и v3. Он показывает
только безопасные агрегаты:

- нормализованные семейства агентов;
- использование API v2 и v3;
- MCP methods, tools и resource operations;
- популярность публичных материалов;
- агрегированные outcomes и состояние версий.

Поисковые тексты, код, IP, исходные `clientInfo`, версии клиентов, полный
User-Agent, cursor, stack traces и внутренние пути на сайте отсутствуют.
Расширенные данные остаются вне web root и при необходимости получаются через
SSH.

## Отклонённые варианты

- оставить текущую публикацию детальных событий;
- закрыть весь dashboard аутентификацией;
- создать отдельные сайты для v2 и v3.

## Последствия

- переход с v2 на v3 виден в одном месте;
- сайт остаётся публичным без публикации пользовательского содержимого;
- точный формат событий, layout, retention и rollout меняются в design без
  отмены ADR-0002;
- публикация сырой телеметрии или отказ от публичного dashboard потребуют нового
  ADR, заменяющего только ADR-0002.
